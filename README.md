# 네일 조합 (이달의 아트 만들기)

레퍼런스 사진 여러 장을 아트보드에 자유롭게 올려 콜라주처럼 조합하고, 이달의 아트로 저장하는 앱.
서버 없이 브라우저 안에서만 동작하고, 데이터는 기기(IndexedDB)에 저장된다. 백업은 구글 드라이브.

## 실행

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/ 에 배포용 파일 생성
```

## 기능

- **팔레트**: 네일을 하나하나 모아두는 곳. 사진 여러 장을 고르면 한 장 = 네일 하나
  - #해시태그: 네일 하나에 여러 개, 태그로 골라보기(전체·#태그·태그 없음), 태그 이름 바꾸기·삭제
  - 여러 개 선택해 한꺼번에 태그 붙이기/빼기·삭제
  - 네일을 누르면 태그 켜고 끄기, ✂️ 자르기, 🧽 지우개, 삭제
- **이달의 아트** 탭: 연도별 목록 → 상세(이미지 저장·삭제·수정하기) / ＋ 새로 만들기 / 작성 중 이어서 하기
  - 연도·월마다 하나씩 저장(같은 달은 덮어쓰기, 다른 아트를 덮어쓸 땐 확인)
  - 캔버스: 헤더·하단 메뉴를 뺀 화면을 꽉 채움 (새 아트는 그 기기 화면 비율, 저장된 아트는 원래 비율 유지)
  - ＋ 네일 → 팔레트에서 여러 개 골라 올림(누른 순서대로 5개씩 한 줄 = 조합 하나)
  - 배경: 추천 색 9가지 + 직접 고르기, 저장 이미지에도 반영
  - 끌어서 이동, 터치하면 아이콘 표시 (터치한 네일은 자동으로 맨 앞)
    - ↘ 누른 채로 끌기: 크기 조절(비율 유지, 회전된 상태에서도)
    - ⟳ 누른 채로 끌기: 회전 (0·90·180·270° 근처에서 딱 맞춤)
    - ✎ 편집: 지우개(한 손가락 지우기, 두 손가락 이동·확대) · 자르기(모서리·상하좌우 핸들, 자유·1:1·3:4, 자른 부분은 제자리에 남음), 되돌리기, 원본으로 — 캔버스 위 복사본만 바뀜
    - × 삭제
- **백업** 탭: 준비 중 (구글 드라이브 연동 코드는 `src/drive.ts`·`src/backup.ts`에 있음, 설정은 아래)

## 구글 드라이브 백업 설정 (무료, 한 번만)

앱이 구글 드라이브에 접근하려면 구글에서 발급하는 "클라이언트 ID"가 필요하다. 비용은 들지 않는다.

1. https://console.cloud.google.com 접속 → 상단에서 **새 프로젝트** 생성 (예: `nail-app`)
2. **API 및 서비스 → 라이브러리**에서 **Google Drive API** 검색 → 사용 설정
3. **API 및 서비스 → OAuth 동의 화면**
   - 사용자 유형: **외부**, 앱 이름·이메일 입력
   - 범위는 추가하지 않아도 됨 (앱이 `drive.appdata`만 요청)
   - **테스트 사용자**에 본인 구글 계정 추가
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 JavaScript 원본**: `http://localhost:5173` 그리고 배포한 https 주소
5. 발급된 클라이언트 ID를 프로젝트 폴더의 `.env.local` 에 저장 (git에 올라가지 않음)

   ```
   VITE_GOOGLE_CLIENT_ID=1234567890-xxxx.apps.googleusercontent.com
   ```

6. `npm run dev` 재시작

참고
- 앱은 드라이브의 **앱 전용 숨김 폴더(appDataFolder)** 만 사용한다. 사용자의 다른 드라이브 파일은 보거나 바꿀 수 없다.
- 구글 로그인은 `localhost` 또는 **https** 주소에서만 된다. 폰에서 쓰려면 https로 배포해야 한다
  (같은 와이파이의 `http://192.168.x.x` 주소로는 구글 로그인이 안 됨).

## 모바일 앱(하이브리드)

Capacitor 설정(`capacitor.config.ts`)이 들어 있다. Xcode / Android Studio 설치 후:

```bash
npx cap add ios && npm run ios
npx cap add android && npm run android
```
